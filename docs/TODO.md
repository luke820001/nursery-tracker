# 待辦清單（下一階段功能）

依業主討論排定優先順序。已完成的 MVP 範圍見 `docs/SPEC.md` §5.2。

## P1 — 出貨單／交苗單範本輸出 ⭐ 業主提出

**需求**：業主上傳自己的表單範本，出貨時系統把批次資料帶入範本欄位，直接輸出成可列印／可傳送的表單。

**可行性**：可行。建議分兩步：

1. **HTML 列印範本（先做，零依賴）**
   * 在設定頁提供「出貨單範本」編輯：標題、場名、地址、電話、備註條款，欄位用 `{{客戶}}`、`{{批次編號}}`、`{{作物}}`、`{{品種}}`、`{{穴盤}}`、`{{盤數}}`、`{{單價}}`、`{{金額}}`、`{{出貨日}}`、`{{交貨方式}}`、`{{送貨地址}}` 等佔位符。
   * 出貨完成後按「列印出貨單」→ 開啟列印檢視 → 手機「分享 → 儲存為 PDF」或直接印。
   * 支援同一客戶同日多批次合併成一張單。
2. **Word/Excel 範本填欄（第二步）**
   * 業主上傳 `.docx`（用 docxtemplater）或 `.xlsx`（用 exceljs）範本，範本內同樣寫 `{{欄位}}`。
   * 前端在手機直接產生檔案並分享；不需要伺服器。
   * 前置：範本檔存在 IndexedDB + 雲端（Google Drive 或 Sheets 附件）。

**資料需求**：`Batch.unitPrice`、`deliveryMethod`、`Customer.address/phone` 已備妥。可再加：出貨單號、稅別、收款狀態。

## P1 — 資料安全

- [ ] 每日自動備份：Apps Script 觸發器每天把試算表複製一份到 Drive 資料夾（保留 30 天）。
- [ ] 同步失敗超過 1 小時 → App 顯示醒目提醒。

## 待討論（來自 GPT 研究報告）

- [ ] 品質四關卡：發芽檢查、成活與缺株、出貨前苗況、裝車確認（含可售率）。
- [ ] 修改稽核軌跡：交期、報廢、出貨差異保留前值／後值／原因／操作人。
- [ ] 種苗標示與產銷履歷欄位（業者名稱地址、品種名、生產地、數量、資材批號），資料保存 3 年。

- [ ] 權限角色（現場／領班／場主）。

## P2 — 現場作業

- [ ] 拍照紀錄（病蟲害、苗況）：照片上傳 Google Drive，紀錄存連結。
- [ ] 語音輸入備註。
- [ ] 條碼／QR：每批次一張標籤貼在穴盤，掃碼直接開批次。
- [ ] 床位容量規劃：每床位可放盤數，排程時顯示某日各床位佔用率（Gemini 報告「苗床熱點圖」簡化版）。
- [ ] 農藥紀錄加「安全進入間隔期 REI」（複雜，待討論）。
- [ ] 季節苗期：作物主檔加夏季／冬季苗期天數，建批次依月份自動帶入。

## P2 — 經營管理

- [ ] 每週出貨預告：Apps Script 每週日寄 Email／Google Chat 給老闆。
- [ ] 客戶價目表：不同客戶不同單價，建批次自動帶入。
- [ ] 收款狀態：未收／已收／月結，出貨後追蹤。
- [ ] 種子庫存：品種、袋數、到期日，播種自動扣。
- [ ] 損耗分析：依作物／季節／床位統計損耗率，回饋到主檔預估值。
