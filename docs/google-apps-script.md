# Google Sheets 雲端同步設定（免費，約 5 分鐘）

App 會把所有資料自動上傳到你的 Google 試算表，同事開啟你分享的「設定連結」就能共用同一份資料。

## 1. 建立試算表與 Apps Script

1. 用種苗場的 Google 帳號開 <https://sheets.new> 建一個新試算表，命名例如 **「吳平種苗廠 育苗資料」**。
2. 上方選單 **擴充功能 → Apps Script**。
3. 把編輯器裡原本的內容全部刪掉，貼上 [`docs/apps-script/Code.gs`](apps-script/Code.gs) 的全部內容。
4. 修改第一行的密語：

   ```js
   const TOKEN = '請改成你們自己的密語';
   ```

   例如 `const TOKEN = 'wuping2026';`。這就是團隊共用的「密碼」。
5. 按 💾 儲存。

## 2. 部署為網頁應用程式

1. 右上角 **部署 → 新增部署作業**。
2. 左邊齒輪 ⚙ 選 **網頁應用程式**。
3. 設定：
   * 說明：`nursery v1`
   * 執行身分：**我**
   * 誰可以存取：**所有人**（App 要能不登入就呼叫；資料仍受密語保護）
4. 按 **部署**，第一次會要求授權 → 選你的帳號 → 「進階」→「前往 … (不安全)」→ 允許。
5. 複製 **網頁應用程式網址**，長得像：

   ```
   https://script.google.com/macros/s/AKfycb.../exec
   ```

## 3. 在 App 裡設定

1. 開啟 App → **設定 → 雲端同步 / 匯出**。
2. 貼上網址到「Apps Script 網頁應用程式網址」，密語填 `wuping2026`（你剛設的）。
3. 按 **立即同步**。成功會顯示「同步完成：上傳 n、下載 n」，頂欄徽章變成 `☁ 已同步`。
4. 回試算表看，會自動出現 `批次總表`、`作業紀錄` 兩張可讀的工作表，以及 `batches` 等原始資料表（請勿手動修改原始表）。

## 4. 讓同事加入

在同一頁按 **🔗 分享團隊設定連結給同事**，用 LINE 傳給同事。同事在手機開啟該連結後：

1. App 自動填好雲端設定並下載全部資料。
2. 提醒同事「加到主畫面」變成 App 圖示。

## 5. 更新 Apps Script 時

之後如果修改 `Code.gs`，要 **部署 → 管理部署作業 → ✏ 編輯 → 版本：新版本 → 部署**，網址不變。

## 常見問題

| 狀況 | 處理 |
|---|---|
| 「密語（token）錯誤」 | App 裡的密語與 `Code.gs` 的 `TOKEN` 不一致 |
| 同步失敗 `HTTP 302` / `Failed to fetch` | 部署時「誰可以存取」不是「所有人」，或忘了按新版本部署 |
| 兩支手機同時改同一批次 | 以最後修改時間為準（後寫者勝） |
| 想換一份新的試算表 | 重新做步驟 1–3，並在每支手機更新網址 |
| 老闆想看報表 | 直接開試算表的 `批次總表`，可用篩選、樞紐分析、圖表 |

## 安全說明

網址 + 密語 = 可讀寫資料。請只在團隊內以 LINE 私訊分享設定連結，不要貼在公開群組。若外洩，改 `TOKEN` 並重新部署即可作廢舊密語。
